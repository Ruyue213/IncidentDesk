# v0.4 engineering beta verification

This version adds optional local Cross-Encoder reranking, concurrent execution within one local worker, project cloud egress controls, and action-to-business verification. See the [retrieval report](../../evals/retrieval-v2/README.md) and the [outcome API and evidence contract](../OUTCOMES.md).

- The data and comparison parameters were frozen before the first model run. The acceptance set contains 32 original queries on eight mechanism families excluded from development. All 128 mode/query/repetition runs completed and all 64 comparisons used identical candidates. Relevant source spans determine recall. On 24 answerable queries, Recall@5 rose from 56.25% to 79.17%, MRR@5 from 0.5812 to 0.7986, and nDCG@5 from 0.4186 to 0.7361. The first-pass p95 rose from 20.94 ms to 2.72 seconds on the tested Mac. Each Cross-Encoder request launches a process and loads the model.
- The frozen adoption gate rejected the default-on change. Hard-negative exposure in the five final slots rose from 19/24 to 20/24. Both modes returned context for all eight no-answer queries. The feature remains opt-in.
- The [synthetic business loop](../../evals/outcomes/synthetic-loop-01.json) passed eight real local API/worker/service checks. A health response of 200 coexisted with a failed business assertion. Recording recovery with that evidence was refused. A later passing probe supported a new operator revision. The record survived an application restart and the aggregate omitted identifiers and private text.
- Local regression passed with 418 backend checks and one Linux-only skip, 11 state tests, and nine browser interaction tests. Tests exercised bounded concurrency, competing approvals, shutdown and checkpoint recovery, model wire policy, reranker cancellation and fallback, and outcome conflict handling.
- A fresh local wheel install passed the CLI startup/shutdown, included UI, project registration, knowledge search and missing-model fallback, runtime queue status, business probe, offline fixture task, and backup/restore checks.

The evaluation ran with local models and test-owned processes. Confirming an operator assessment does not prove independent incident accuracy. Shared deployment, tenant controls, secret-manager integration and real multi-operator reliability statistics remain separate milestones.
